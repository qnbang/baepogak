# 🚀 바이브코딩 배포 전 체크리스트 (Vibe-Ship Checklist)

> **AI로 웹사이트 만들었어요? 배포 전에 이것만 확인하세요.**
> 커서·러버블·v0·볼트·Claude로 후딱 만든 사이트에 빠지기 쉬운 **"배포하고 나서 참교육 당하는"** 함정 12가지 + 복붙 프롬프트.
>
> 겉보기엔 잘 돌아가는데, 실제로 사람들이 쓰기 시작하면 터지는 것들입니다. 비개발자도 이해하도록 **"왜 위험한지 → 안 하면 무슨 일 → 어떻게"** 순으로 정리했습니다.

---

## 이 팩은 뭔가요?

AI가 짜주는 코드는 "화면에서 돌아가는 것"까지는 잘합니다. 하지만 **실제 서비스가 되려면 필요한 기본기**(데이터 안 날리기, 돈 계산 정확히, 카톡 공유 미리보기 등)는 시키지 않으면 빠져 있는 경우가 많습니다.

이 저장소는 그 빠진 기본기를 **① 체크리스트(이 문서) ② 복붙 프롬프트([prompts.md](prompts.md)) ③ 그대로 붙여쓰는 코드 조각([snippets/](snippets/))** 세 가지로 채워줍니다.

- **커서·러버블·v0 유저** → [prompts.md](prompts.md)의 프롬프트를 복붙하세요.
- **Claude Code 유저** → `.claude/` 스킬을 깔면 자동으로 점검·수정해줍니다.
- **직접 코드 넣고 싶으면** → [snippets/](snippets/)에서 의존성 없는 조각을 가져가세요.

## A. 데이터를 지키는 것 (안 하면 복구 불가)

### ① 백업 없이 덮어쓰기 금지
- **왜:** 어드민에서 실수로 잘못 저장하면, 직전 상태로 되돌릴 방법이 없습니다.
- **안 하면:** 고객이 애써 넣은 데이터가 한 번의 오조작으로 영영 사라집니다.
- **어떻게:** 데이터를 통째로 덮어쓰기 **직전에**, 기존 파일을 날짜 붙여 한 벌 복사(`content-20260707-1830.json`). 그러면 언제든 롤백 가능. → [snippets/js/save-with-backup.ts](snippets/js/save-with-backup.ts)

### ② 삭제는 "진짜 삭제" 말고 "숨김 처리"
- **왜:** 고객이 "지워주세요" 해도, 분쟁·실수·법적 보존의무 때문에 실제로 지우면 안 되는 데이터가 있습니다.
- **안 하면:** 실수로 지운 걸 복구 못 하고, "정말 삭제 요청을 받았다"는 증거도 사라집니다.
- **어떻게:** 삭제 = 데이터에 `deleted_at`(삭제한 시각)만 기록하고 화면에서만 숨기기. 실제 데이터는 남겨둡니다. → [snippets/js/soft-delete.ts](snippets/js/soft-delete.ts)

## B. 권한과 보안 (프론트만 막으면 다 뚫림)

### ③ 권한 검사는 반드시 "서버"에서
- **왜:** 버튼을 숨기거나 화면에서 막아도, 사용자는 서버 주소(API)를 직접 호출할 수 있습니다.
- **안 하면:** 권한 없는 사람이 관리자 기능(저장·삭제)을 그냥 실행합니다.
- **어떻게:** 최종 권한 검사는 **서버 코드**에서. "버튼 안 보이니 괜찮겠지"는 착각입니다.

### ④ 비밀번호·키를 코드에 하드코딩 금지
- **왜:** `const PW = "1234"` 같은 기본값은 사실상 공개된 비번입니다.
- **안 하면:** 깃허브·브라우저에서 누구나 볼 수 있어 어드민이 뚫립니다.
- **어떻게:** 비밀값은 환경변수(`process.env`)로. **환경변수가 없으면 통과가 아니라 거부**(fail-closed). → [snippets/js/require-env-secret.ts](snippets/js/require-env-secret.ts)

## C. 바깥세상은 항상 말썽 (외부 API·결제·문자)

### ⑤ 외부 API는 "항상 실패한다"고 가정
- **왜:** 결제·문자·이메일·로그인·검색 API는 늦거나, 실패하거나, 같은 요청이 두 번 옵니다.
- **안 하면:** "결제는 됐는데 주문이 없다", "문자가 두 번 갔다" 같은 사고.
- **어떻게:** 타임아웃 + 재시도(2~3회) + **멱등성**(같은 요청 두 번 = 결과 하나). 여러 건 처리할 땐 한 건 실패가 전체를 멈추지 않게. → [snippets/js/fetch-with-retry.ts](snippets/js/fetch-with-retry.ts)

## D. 나중에 문제 터졌을 때 (로그·시간·돈)

### ⑥ 로그 없이 운영 금지
- **왜:** 장애가 나도 로그가 없으면 원인을 전부 추측해야 합니다.
- **안 하면:** "왜 안 되지?"를 며칠 헤맵니다. 특히 돈 관련은 누가 뭘 바꿨는지 못 찾습니다.
- **어떻게:** 최소한 에러를 서버 로그(`console.error`)에 남기기. 돈을 바꾸는 곳은 "무엇을 얼마로 바꿨나" 한 줄 기록. → [snippets/js/log.ts](snippets/js/log.ts)

### ⑦ 시간은 "세계표준(UTC)로 저장, 화면엔 한국시간"
- **왜:** "7월 3일 0시"가 한국시간인지 UTC인지 모호하면, 쿠폰 만료·예약·정산이 몇 시간씩 어긋납니다.
- **안 하면:** 자정 마감이 오전 9시에 끝나버리는 식의 버그.
- **어떻게:** 저장은 UTC(또는 `+09:00` 오프셋 명시), 화면에 보일 때 한국시간으로 변환. → [snippets/js/kst-time.ts](snippets/js/kst-time.ts)

### ⑧ 금액 계산에 소수(float) 쓰지 말기
- **왜:** 컴퓨터는 `0.9`, `0.1` 같은 소수를 정확히 저장하지 못합니다.
- **안 하면:** `9900 × 0.9`가 `8909.999...`가 되어 정산 금액이 1원씩 어긋납니다.
- **어떻게:** 금액은 **원 단위 정수**로. `× 0.9` 대신 `× 90 ÷ 100`. 반올림 규칙은 한 곳에 고정. → [snippets/js/money.ts](snippets/js/money.ts)

## E. 남들에게 보이는 것 (공유·검색·분석)

### ⑨ OG 태그 — 카톡 공유 미리보기
- **왜:** OG(오픈그래프) 태그가 없으면, 링크를 카톡·인스타에 붙였을 때 **휑한 주소만** 뜹니다.
- **안 하면:** 어렵게 만든 사이트가 공유될 때 싸구려로 보입니다.
- **어떻게:** `og:title`, `og:description`, `og:image`(대표 이미지), `og:url`을 `<head>`에 추가. → [정적 HTML](snippets/seo/meta-tags.html) · [Next.js](snippets/seo/nextjs-metadata.ts)

### ⑩ 페이지 제목 + 설명 (SEO 기본)
- **왜:** `<title>`과 meta description이 검색결과·브라우저 탭에 뜨는 얼굴입니다.
- **안 하면:** 구글에 "index"라고 뜨거나 아예 안 걸립니다.
- **어떻게:** 의미 있는 제목 + 한 줄 설명 + `<html lang="ko">` + favicon. → [정적 HTML](snippets/seo/meta-tags.html) · [Next.js](snippets/seo/nextjs-metadata.ts)

### ⑪ robots.txt / sitemap.xml
- **왜:** 검색엔진에게 "여기 있어요, 이 페이지들 봐주세요"라고 알려주는 파일.
- **안 하면:** 구글이 사이트를 늦게 찾거나 일부만 수집합니다.
- **어떻게:** 루트에 `robots.txt` + `sitemap.xml`. → [robots.txt](snippets/seo/robots.txt) · [sitemap.xml](snippets/seo/sitemap.xml)

### ⑫ GEO — AI가 내 사이트를 인용하게
- **왜:** 요즘은 사람들이 ChatGPT·퍼플렉시티에게 물어봅니다. AI가 답할 때 내 사이트가 인용되면 새 유입 경로가 됩니다.
- **안 하면:** 검색은 챙겼는데 AI 답변에서는 안 보입니다.
- **어떻게:** 구조화 데이터(JSON-LD, schema.org)로 "이 페이지가 무엇인지" 기계가 읽게 표시 + 명확한 제목·요약. → [snippets/seo/json-ld.html](snippets/seo/json-ld.html)

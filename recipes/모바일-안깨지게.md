# 모바일에서 안 깨지게 — 반응형 5원칙

바이브코딩으로 만든 사이트가 **PC에선 멀쩡한데 폰에서 옆으로 튀어나오거나 깨지는** 건 거의 항상 아래 5가지 중 하나 때문입니다. 두더지잡기(하나 고치면 딴 데 터짐)를 피하려면 처음부터 다섯 개를 같이 지키세요.

### 1. 반응형은 처음부터 `@media`로 분리
데스크탑용 CSS를 전역에 깔아두고 나중에 모바일을 덧대면 계속 충돌합니다. 작업하는 내내 **모바일(폭 390px)과 PC를 같이** 확인하세요. 무거운 배경 효과(패럴랙스)는 모바일에서 끄고 세로 스크롤로.

### 2. `width:100%` + padding엔 `box-sizing:border-box`
padding을 준 요소에 `width:100%`를 주면 padding만큼 넘칩니다. 루트에 아래를 깔아두면 대부분 해결:
```css
*, *::before, *::after { box-sizing: border-box; }
html, body { overflow-x: hidden; }
```
그리고 각 화면 폭에서 가로 스크롤이 생기는지(옆으로 튀는지) 꼭 확인하세요.

### 3. 나란히 배치는 flex로 묶기
요소마다 `position:absolute`에 좌표를 박아 정렬하면 브라우저·기기마다 어긋납니다. 나란히 둘 것은 **flex 컨테이너**로 묶으세요:
```css
.row { display: flex; align-items: center; gap: 16px; }
```

### 4. 최종 확인은 진짜 폰으로 (특히 아이폰 사파리)
개발 도구의 모바일 미리보기만 믿지 마세요. 아이폰 사파리는 특유의 렌더링 차이가 있습니다. **실기기 스크린샷**으로 마지막에 한 번 보세요.

### 5. 캐시 대비 — 저장 데이터에 버전 필드
수정했는데 예전 화면이 계속 보이면 브라우저·CDN 캐시 때문입니다. 저장하는 데이터에 `_v` 같은 버전 필드를 두고, 값이 안 맞으면 기본값을 쓰게 하세요. 수정 후엔 강력 새로고침(⌘⇧R / Ctrl+F5)으로 확인.
